Kandela

Kebijakan privasi

Diperbarui 20 November 2026. Kandela adalah prototipe edukatif untuk belajar membaca chart. Semua chart, berita, dan angka adalah data simulasi, bukan saran investasi.

Ringkasnya: kamu bisa memakai Kandela tanpa login (mode tamu, tidak ada data terkirim ke server soal dirimu). Kalau kamu masuk dengan Google, kami menyimpan nama, foto, email, dan riwayat latihanmu supaya progres dan papan skor bisa jalan. Kamu bisa menghapus semuanya kapan saja.

Data yang disimpan

  • Mode tamu: progres latihan disimpan hanya di browsermu (localStorage). Tidak ada akun, tidak dikirim ke server.
  • Kalau login Google: alamat email, nama tampilan, dan foto profil yang diberikan Google; serta riwayat latihanmu (arah keputusan, stop loss, target, risiko, skor, hasil) beserta XP, streak, dan level.

Tujuan

  • Menyimpan progres belajarmu agar tetap ada saat kamu masuk lagi dari perangkat lain.
  • Menampilkan papan skor. Papan skor hanya memuat nama tampilan, level, dan skor rata-rata — tidak ada email.

Tempat penyimpanan

Data akun dan latihan disimpan di Supabase (Postgres). Akses dibatasi Row Level Security sehingga tiap pengguna hanya bisa membaca barisnya sendiri; papan skor hanya mengekspos nama tampilan, level, dan rata-rata.

Pihak ketiga

  • Google — hanya untuk login (OAuth). Kami menerima email, nama, dan foto dari Google.
  • Supabase — basis data dan autentikasi.
  • Groq — pertanyaanmu ke mentor chat dikirim ke Groq untuk dijawab model bahasa open source. Jangan menulis data pribadi di kolom chat. Kami tidak menyimpan isi pertanyaanmu di basis data.
  • Vercel — hosting, log server, dan statistik kunjungan agregat (tanpa cookie pelacak).

Kami tidak menjual datamu dan tidak memakainya untuk iklan.

Cookie

Kami tidak memasang cookie iklan. Supabase menyimpan token sesi loginmu di penyimpanan browser agar kamu tetap masuk. Statistik Vercel bersifat agregat dan tanpa cookie.

Menghapus akun dan data

Di halaman utama bagian Progres (saat masuk), ada tombol "Hapus akun dan data saya" dengan konfirmasi dua langkah. Menekannya akan menghapus profil, progres, dan seluruh riwayat latihanmu, lalu menghapus akunmu dari sistem autentikasi. Tindakan ini permanen dan tidak bisa dibatalkan. Login lagi setelah itu akan membuat akun baru yang kosong.

Tidak bisa mengakses tombolnya? Hubungi kontak di bawah dan sebutkan email akunmu.

Kontak

Ini proyek portofolio mahasiswa. Untuk permintaan hapus data atau pertanyaan privasi, buka profil GitHub pembuat (faeezzy) dan ajukan lewat issue atau kontak yang tertera di sana.
